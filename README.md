# AI-Driven Adaptive Cyber Defense and Automated Threat Hunting Platform

A hackathon starter project for detecting, correlating, explaining, and simulating responses to multi-stage cyber threats across authentication, endpoint, network, and cloud audit logs.

## Project Status

This repository contains the initial application skeleton, shared API contract, sample event fixtures, and team ownership boundaries. Detection and response modules are starter interfaces intended for parallel implementation.

## Quick Start

Backend and frontend setup instructions are in [docs/SETUP.md](docs/SETUP.md). The API surface is documented in [docs/API_CONTRACT.md](docs/API_CONTRACT.md).

## Project Layout

- `frontend/`: React and Vite dashboard
- `backend/`: FastAPI service and threat-analysis modules
- `datasets/`: small synthetic log samples and labeled scenarios
- `docs/`: requirements, architecture, setup, team ownership, and API contract
- `screenshots/`: space for dashboard and demo captures

## Team Workflow

Work within the folder assigned in [docs/TEAM_OWNERSHIP.md](docs/TEAM_OWNERSHIP.md). Coordinate cross-module changes through the shared API contract and architecture document to keep parallel work independent.
